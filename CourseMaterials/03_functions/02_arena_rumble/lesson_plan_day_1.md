## Essential Questions

- How do we use variables in games?
- How do we model complex interactions between sprites?

## Lesson Plan

In this lesson, students work by themselves to create a relatively simple game
that involves a bunch of "pop ups". The purpose is to get them back in the habit
of creating games via the game loop algorithm and to have them use variables in
a game-like environment for the first time. The reason that students work
individually is to identify students who have been overly dependent on their
partners throughout the previous lessons.

### Actual Lesson

- Review
    - Variables

    - Getting user input
    - Game loop algorithm

    - Program that draws hexagons of increasing size
    - Mess with it so it changes colors
    - Mess with it to make it turn **111 degrees**
- Classic arena game
    - Two players
    - Show game and challenge someone
- Show blocks going to need
    - `go to(random position)`
    - `timer`
- Design the first three sprites as a class
    - Don't do "chasing sprite" until later
- Emphasize various check points
    - Start with first player sprite
    - Then do button sprite
    - Then do chasing sprite
    - Then duplicate player sprite
- Go!
    - Do **individually**!
