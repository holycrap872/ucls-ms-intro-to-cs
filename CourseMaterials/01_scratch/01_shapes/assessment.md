0. What is the difference between sequential and parallel algorithms?
    - Sequential algorithms complete one step at a time in order
    - Parallel algorithms must wait for all steps to complete before moving on
    - Sequential algorithms can only be used for sorting
    - Parallel algorithms combine all steps into one big step

0. Why are loops useful when writing programs?
    - If you can identify a pattern, they allow for shorter programs
    - When code is more than a full screen in length, they can be nested
    - If you trust the computer, it will be creative for you
    - When multiple things are happening at once, it will link to the start
0. What are nested loops?
    - One loop "inside" another loop
    - Two loops "next to" each other
    - Loops with the same number of blocks in them
    - A loop directly under the "when green flag clicked" block
0. What's the advantage of using nested loops when drawing patterns?
    - They can create more complex patterns with less code
    - They make the program run faster
    - They use less memory
    - They are easier to understand
