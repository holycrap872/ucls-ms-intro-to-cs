## Essential Questions

- How can we use sensing to provide feedback to a system?
- How can we break down a goal into easy to accomplish sub-tasks?

## Lesson Plan:

### Setup

- Have `tracking_bot_final.sb3` open and code hidden
    - https://scratch.mit.edu/projects/932644043
- Have `tracking_bot_skeleton.sb3` available via Schoology
    - https://scratch.mit.edu/projects/896826066
    - Students will "remix" it

### Pacing

- Review (5m)
- Tracking Bot Discussion (5m)
- Tracking Bot Group Work (30m)

### Actual Lesson

- Review
    - What did we do last class?
    - What are sensors?
    - How did the game work?
        - As a class, come up with conditionals that they see
            - Put up answers on board
- Show blocks going to need
    - `wait until` block
- Emphasize various check points
    - Start with drawing sprite
    - Move to tracking bot sprite
- If need to stretch:
    - Create a new level and make it the "first" level
        - Explain how proud I am of my level because requires difficult movements
    - Show "broadcast" and "when I receive"
    - Give students ability to play eachother's games and provide feedback
